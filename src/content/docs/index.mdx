## Firefox Enterprise

Firefox Enterprise is a dedicated version of Firefox for organizations with strict security, governance and compliance requirements, now available in early access.
It is managed from an Admin Console that runs on your own infrastructure, adding centralized policy management, company sign-in, data protection, update control and security event visibility.
Firefox and Firefox ESR can continue to be managed with the same tools and policies.

## Configuring Firefox as an enterprise browser

Organizations have fine-grained administrative and orchestration control of the browser's behavior by using enterprise policies in [Firefox and Firefox Extended Support Release (ESR)](/guides/firefox-channels/).
Firefox can be deployed and managed with common enterprise configuration systems such as Microsoft Intune, JAMF, MDM, and other software-distribution platforms.
