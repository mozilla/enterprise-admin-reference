Configures a list of bookmarks managed by an administrator that cannot be changed by the user.

The bookmarks are only added as a button on the personal toolbar, they are not in the bookmarks folder.

The syntax of this policy is based on the [Chrome ManagedBookmarks policy](https://cloud.google.com/docs/chrome-enterprise/policies/?policy=ManagedBookmarks), with the addition of the Firefox-specific `favicon` property.

## Values

The first entry in the list names the toolbar folder, and the entries after it are the bookmarks:

- `toplevel_name`: The name of the folder button added to the bookmarks toolbar.
  Only used in the first entry.
- `name`: The name shown for a bookmark or folder.
  Firefox skips bookmarks without a `name`, and shows folders without a `name` as **Subfolder**.
- `url`: The address the bookmark opens.
  A `javascript:` URL creates a bookmarklet.
- `favicon`: The URL of an icon to show for the bookmark.
  Must be a `data:`, `http:` or `https:` URL.
- `children`: A list of bookmarks to put in a folder.
  Folders can be nested.

### Adding a list of bookmarks

This example adds a folder to the bookmarks toolbar.
There's no `toplevel_name` entry, so Firefox names the folder **Managed bookmarks**.
By default, Firefox only shows the toolbar on the new tab page, so [`DisplayBookmarksToolbar`](/reference/policies/displaybookmarkstoolbar/) is set to `always`:

```json
{
  "policies": {
    "ManagedBookmarks": [
      { "name": "Intranet", "url": "https://intranet.example.com" },
      { "name": "IT help desk", "url": "https://help.example.com" },
      { "name": "Expenses", "url": "https://expenses.example.com" }
    ],
    "DisplayBookmarksToolbar": "always"
  }
}
```

### Organizing bookmarks into folders

The `toplevel_name` entry sets the name of the toolbar folder.
An entry with `children` is a folder, and folders can contain other folders:

```json
{
  "policies": {
    "ManagedBookmarks": [
      { "toplevel_name": "Example Corp" },
      { "name": "Intranet", "url": "https://intranet.example.com" },
      {
        "name": "HR",
        "children": [
          { "name": "Benefits", "url": "https://hr.example.com/benefits" },
          { "name": "Time off", "url": "https://hr.example.com/time-off" }
        ]
      },
      {
        "name": "Engineering",
        "children": [
          { "name": "Code review", "url": "https://code.example.com" },
          {
            "name": "Runbooks",
            "children": [{ "name": "On-call", "url": "https://wiki.example.com/on-call" }]
          }
        ]
      }
    ],
    "DisplayBookmarksToolbar": "always"
  }
}
```

## Windows (GPO)

Software\Policies\Mozilla\Firefox\ManagedBookmarks (REG_MULTI_SZ) =

```
[
  {
    "toplevel_name": "My managed bookmarks folder"
  },
  {
    "url": "example.com",
    "name": "Example",
    "favicon": "https://example.com/favicon.ico"
  },
  {
    "name": "Mozilla links",
    "children": [
      {
        "url": "https://mozilla.org",
        "name": "Mozilla.org"
      },
      {
        "url": "https://support.mozilla.org/",
        "name": "SUMO"
      }
    ]
  }
]
```

## macOS

```xml
<dict>
  <key>ManagedBookmarks</key>
  <array>
    <dict>
      <key>toplevel_name</key>
      <string>My managed bookmarks folder</string>
    </dict>
    <dict>
      <key>url</key>
      <string>example.com</string>
      <key>name</key>
      <string>Example</string>
      <key>favicon</key>
      <string>https://example.com/favicon.ico</string>
    </dict>
    <dict>
      <key>name</key>
      <string>Mozilla links</string>
      <key>children</key>
      <array>
        <dict>
          <key>url</key>
          <string>https://mozilla.org</string>
          <key>name</key>
          <string>Mozilla.org</string>
        </dict>
        <dict>
          <key>url</key>
          <string>https://support.mozilla.org/</string>
          <key>name</key>
          <string>SUMO</string>
        </dict>
      </array>
    </dict>
  </array>
</dict>
```
