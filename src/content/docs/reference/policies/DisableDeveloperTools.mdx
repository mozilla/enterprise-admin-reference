## Compatibility

<PolicyCompat policy="DisableDeveloperTools" />

**CCK2 Equivalent:** `removeDeveloperTools`\
**Preferences Affected:** `devtools.policy.disabled`

<dict>
  <key>DisableDeveloperTools</key>
