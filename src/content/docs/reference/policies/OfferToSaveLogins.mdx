---
title: "OfferToSaveLogins"
description: "Control whether or not Firefox offers to save passwords."
category: "Password manager"
---

Control whether or not Firefox offers to save passwords.

## Values

- Set to `true` to offer to save logins and passwords, and prevent the user from changing it.
- Set to `false` to stop offering to save logins and passwords, and prevent the user from changing it.

## Examples

<PolicyExample policy="OfferToSaveLogins" />

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\OfferToSaveLogins = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>OfferToSaveLogins</key>
  <true/> | <false/>
</dict>
```
