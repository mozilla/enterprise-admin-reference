Configure the AI chatbot sidebar, including which built-in providers are available and the ability to add custom providers.
For more information, see [Access AI chatbots in Firefox](https://support.mozilla.org/en-US/kb/ai-chatbot) on support.mozilla.org.

## Values

- `Providers`: Configures the available AI chatbot providers.
  - `Add`: An array of custom provider objects to add.
    Each object accepts the following properties:
    - `url` (required): The URL of the AI chatbot provider.
    - `name` (required): Display name for the provider.
    - `id` (required): Unique identifier for the provider.
    - `iconUrl`: URL of the provider's icon.
    - `queryParam`: Query parameter name used to pass prompts to the provider.
      Firefox sends prompts to custom providers in the `q` query parameter, so set `queryParam` if your bot or provider expects something different.
  - `BuiltIn`: An object to remove specific built-in providers.
    Set a provider key to `false` to remove it.
    To add a provider that isn't already listed, use the `Add` key.
    The following built-in providers are available:
    - `Anthropic Claude`
    - `ChatGPT`
    - `Copilot`
    - `Google Gemini`
    - `HuggingChat`
    - `Mistral Vibe`
    - `localhost`
    - `Le Chat Mistral` (_Deprecated_. Use `Mistral Vibe` instead.)
  - `Default`: The `name` of the provider to use as the default, for example `Anthropic Claude` or the `name` of a provider in `Add`.
- `Prompts`: Configures the AI chatbot prompt suggestions.
  - `Enabled`: Set to `true` to enable prompt suggestions or `false` to disable them.
  - `BuiltIn`: An object to remove individual built-in prompts.
    Set a prompt key to `false` to remove it.
    The following built-in prompts are available:
    - `Summarize`
    - `Explain`
    - `Quiz`
    - `Proofread`

## Examples

<PolicyExample policy="AIChatbot" />

### Setting your organization's chat provider as the default

This example adds a company-approved chatbot next to the built-in providers and selects it for users who haven't already picked one.
`Default` must match the provider's `name`, not its `id`:

```json
{
  "policies": {
    "AIChatbot": {
      "Providers": {
        "Add": [
          {
            "url": "https://ai.example.com",
            "name": "Example AI",
            "id": "example-ai",
            "iconUrl": "https://ai.example.com/icon.png"
          }
        ],
        "Default": "Example AI"
      }
    }
  }
}
```

### Using on-device models

If you run a chatbot on each device, add it as a custom provider so prompts and page content don't leave the device.
Firefox opens the provider's `url` as a web page in the sidebar and passes prompts in the `q` query parameter, so the server must provide a chat web interface, not just an inference API.
It must also process requests itself rather than forwarding them to an external service.
Setting `localhost` to `true` in `BuiltIn` doesn't show the built-in localhost provider, so use `Add` with the address your server listens on.
Make sure the server is installed and running on every device that receives this policy.
Another application listening on that port could receive users' prompts.
This example also removes the built-in cloud providers so users can't choose one instead:

```json
{
  "policies": {
    "AIChatbot": {
      "Providers": {
        "Add": [
          {
            "url": "http://localhost:8080",
            "name": "Local model",
            "id": "local-model"
          }
        ],
        "BuiltIn": {
          "Anthropic Claude": false,
          "ChatGPT": false,
          "Copilot": false,
          "Google Gemini": false,
          "HuggingChat": false,
          "Mistral Vibe": false
        },
        "Default": "Local model"
      }
    }
  }
}
```

### Turning off prompt suggestions

This example removes the built-in prompts, such as Summarize and Explain, and the prompt shortcut that appears when users select text on a page.
Users can still type their own prompts in the chatbot in the sidebar:

```json
{
  "policies": {
    "AIChatbot": {
      "Prompts": {
        "Enabled": false
      }
    }
  }
}
```
