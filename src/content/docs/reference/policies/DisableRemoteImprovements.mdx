Prevent Firefox from applying performance, stability, and feature changes between updates.

## Examples

<PolicyExample policy="DisableRemoteImprovements" />

## Values

- Set to `true` to stop Firefox applying remotely configured changes between updates.
- Set to `false` to leave remote improvements enabled. This is the same as not setting the policy.

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\DisableRemoteImprovements = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>DisableRemoteImprovements</key>
  <true/> | <false/>
</dict>
```
