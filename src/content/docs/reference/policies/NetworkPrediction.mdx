Enable or disable network prediction ([DNS prefetching](https://developer.mozilla.org/en-US/docs/Glossary/Prefetch#dns_prefetching)).

## Compatibility

<PolicyCompat policy="NetworkPrediction" />

**CCK2 Equivalent:** N/A\
**Preferences Affected:** `network.dns.disablePrefetch`, `network.dns.disablePrefetchFromHTTPS`

## Examples

<PolicyExample policy="NetworkPrediction" />

## Values

- Set to `true` to allow DNS prefetching, and lock the setting.
- Set to `false` to stop DNS prefetching, over both HTTP and HTTPS, and lock the setting.

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\NetworkPrediction = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>NetworkPrediction</key>
  <true/> | <false/>
</dict>
```
