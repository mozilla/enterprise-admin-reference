Enable or disable the detection of captive portals.

## Compatibility

<PolicyCompat policy="CaptivePortal" />

**CCK2 Equivalent:** N/A\
**Preferences Affected:** `network.captive-portal-service.enabled`

## Examples

<PolicyExample policy="CaptivePortal" />

## Values

- Set to `true` to enable captive portal detection, and prevent the user from changing it.
- Set to `false` to disable captive portal detection, and prevent the user from changing it.

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\CaptivePortal = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>CaptivePortal</key>
  <true/> | <false/>
</dict>
```
