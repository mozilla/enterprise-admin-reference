Set whether or not the [search bar](https://support.mozilla.org/en-US/kb/add-search-bar-firefox-toolbar) is displayed.

## Compatibility

<PolicyCompat policy="SearchBar" />

**CCK2 Equivalent:** `showSearchBar`\
**Preferences Affected:** N/A

## Examples

<PolicyExample policy="SearchBar" />

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\SearchBar = "unified" | "separate"
```

## Windows (Intune)

OMA-URI:

```url
./Device/Vendor/MSFT/Policy/Config/Firefox~Policy~firefox/SearchBar
```

Value (string):

```xml
<enabled/>
<data id="SearchBar" value="unified | separate"/>
```

## macOS

```xml
<dict>
  <key>SearchBar</key>
  <string>unified | separate</string>
</dict>
```
