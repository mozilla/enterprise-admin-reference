Remove the ability to import data from other browsers.

## Compatibility

<PolicyCompat policy="DisableProfileImport" />

**CCK2 Equivalent:** N/A\
**Preferences Affected:** N/A

## Examples

<PolicyExample policy="DisableProfileImport" />

## Values

- Set to `true` to remove the option to import data from another browser, including the import wizard.
- Set to `false` to leave importing available. This is the same as not setting the policy.

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\DisableProfileImport = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>DisableProfileImport</key>
  <true/> | <false/>
</dict>
```
