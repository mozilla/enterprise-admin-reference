Configure sign-out behavior for enterprise users.

By default, the session is signed out when the browser closes, so the next launch requires the user to sign in again.
Set this policy to lock the session instead, so that returning users only need to unlock it through operating system authentication rather than going through the full SSO sign-in.

## Values

`SignOut` accepts one or more of the following keys, one for each way the browser can close:

- `Shutdown`: The browser shuts down.
- `Restart`: The browser restarts to apply a pending update.
- `Crash`: Repeated crashes stop the browser from restarting itself.

Each key takes an object with a required `Action`, which is one of:

- `lock`: Lock the session, so the next launch only requires the user to unlock.
- `signout`: Sign the session out, so the next launch requires a full sign-in.
  This is what happens when the key is not set.
