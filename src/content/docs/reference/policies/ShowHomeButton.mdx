Show the home button on the toolbar.

Future versions of Firefox will not show the home button by default.

## Compatibility

<PolicyCompat policy="ShowHomeButton" />

**CCK2 Equivalent:** N/A\
**Preferences Affected:** N/A

## Examples

<PolicyExample policy="ShowHomeButton" />

## Values

- Set to `true` to add the home button to the toolbar, and stop it being removed by default.
- Set to `false` to remove the home button from the toolbar.

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\ShowHomeButton = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>ShowHomeButton</key>
  <true/> | <false/>
</dict>
```
