Disable safe mode ([Troubleshoot Mode](https://support.mozilla.org/en-US/kb/diagnose-firefox-issues-using-troubleshoot-mode)) within the browser.

On Windows, this disables safe mode via the command line as well.

## Compatibility

<PolicyCompat policy="DisableSafeMode" />

Windows and macOS only.

**CCK2 Equivalent:** `disableSafeMode`\
**Preferences Affected:** N/A

## Examples

<PolicyExample policy="DisableSafeMode" />

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\DisableSafeMode = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>DisableSafeMode</key>
  <true/> | <false/>
</dict>
```
