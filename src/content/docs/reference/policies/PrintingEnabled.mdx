Enable or disable printing.

## Compatibility

<PolicyCompat policy="PrintingEnabled" />

**CCK2 Equivalent:** N/A\
**Preferences Affected:** `print.enabled`

## Examples

<PolicyExample policy="PrintingEnabled" />

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\PrintingEnabled = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>PrintingEnabled</key>
  <true/> | <false/>
</dict>
```
