Prevent the built-in VPN from being available to users.

## Compatibility

<PolicyCompat policy="IPProtectionAvailable" />

**CCK2 Equivalent:** N/A\
**Preferences Affected:** `browser.ipProtection.enabled`

## Examples

<PolicyExample policy="IPProtectionAvailable" />

## Values

- Set to `true` to leave the built-in VPN available. This is the same as not setting the policy.
- Set to `false` to make the built-in VPN unavailable to users.

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\IPProtectionAvailable = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>IPProtectionAvailable</key>
  <true/> | <false/>
</dict>
```
