title: "Sync"
description: "Enable or disable sync and define which data to include."

Controls whether [sync](https://www.firefox.com/en-US/features/sync/) should be enabled and which features should be enabled for syncing.

## Values

- `Locked`: A boolean. Whether the policy is **enforced**. This decides how every other key behaves. Leaving it out is the same as `false`.
- `Enabled`: A boolean. Turns sync on or off and stops users from changing that. **Only has an effect when `Locked` is `true`.**
- `Bookmarks`, `History`, `OpenTabs`, `Passwords`, `Addresses`, `PaymentMethods`, `Addons`, `Settings`: A boolean. Whether that data type syncs or doesn't. Unset data types are not managed by the policy.

## Explanation

How these values work together:

| `Locked`         | `Enabled` | Syncing?     | The data type values set | The data types unset                |
| ---------------- | --------- | ------------ | ------------------------ | ----------------------------------- |
| `false` or unset | any       | Users decide | are suggestions          | use Firefox defaults as suggestions |
| `true`           | unset     | Users decide | are enforced             | use Firefox defaults as suggestions |
| `true`           | `false`   | No           | have no effect           | have no effect                      |
| `true`           | `true`    | Yes\*        | are enforced             | use Firefox defaults as suggestions |

\* The user must be signed in to a Mozilla account.

**Notice**:

- `Enabled` is ignored completely with `Locked` set to `false`.
- Data types you leave out stay under the user's control, even though the policy is locked.

### Turning sync off

This configuration turns sync off and stops users from turning it back on:

```json
{
  "policies": {
    "Sync": {
      "Enabled": false,
      "Locked": true
    }
  }
}
```

### Never syncing passwords

This configuration stops passwords from syncing and leaves every other choice to the user:

```json
{
  "policies": {
    "Sync": {
      "Passwords": false,
      "Locked": true
    }
  }
}
```
