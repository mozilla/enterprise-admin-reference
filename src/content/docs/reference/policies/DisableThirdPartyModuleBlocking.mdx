---
title: "DisableThirdPartyModuleBlocking"
description: "Do not allow blocking third-party modules from the 'about:third-party' page."
category: "Security"
---

Stop users from blocking third-party modules (DLLs) on the `about:third-party` page.

Set this policy with Group Policy.
Firefox reads it from the registry at startup and skips the user's blocklist, so any modules the user blocked will load.
In `policies.json`, the policy hides the block buttons, but modules the user already blocked will stay blocked.

In Firefox Enterprise, setting the policy in the Admin Console has the same effect as Group Policy.

## Values

- Set to `true` to stop users blocking third-party modules from `about:third-party`.
- Set to `false` to leave third-party module blocking available. This is the same as not setting the policy.

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\DisableThirdPartyModuleBlocking = 0x1 | 0x0
```
