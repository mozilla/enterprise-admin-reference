Enable or disable file selection dialogs.

## Compatibility

<PolicyCompat policy="AllowFileSelectionDialogs" />

**CCK2 Equivalent:** N/A\

<PolicyExample policy="AllowFileSelectionDialogs" />

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\AllowFileSelectionDialogs = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>AllowFileSelectionDialogs</key>
  <true/> | <false/>
</dict>
```
