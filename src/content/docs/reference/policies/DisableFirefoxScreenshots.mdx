## Compatibility

<PolicyCompat policy="DisableFirefoxScreenshots" />

**CCK2 Equivalent:** N/A\

<PolicyExample policy="DisableFirefoxScreenshots" />

```
Software\Policies\Mozilla\Firefox\DisableFirefoxScreenshots = 0x1 | 0x0
```

## macOS

```xml
<dict>
  <key>DisableFirefoxScreenshots</key>
  <true/> | <false/>
</dict>
```
