---
title: "DisableLocalPolicies"
description: "Disable all local policy sources (policies.json, Windows GPO and macOS plist)."
category: "Miscellaneous"
---

Disable reading policies from local policy sources.

## Compatibility

<PolicyCompat policy="DisableLocalPolicies" />

**CCK2 Equivalent:** N/A\
**Preferences Affected:** N/A

:::caution[Limitation]
The policy cannot be applied by policies.json, Windows GPO or macOS plist.
:::

## Values

- Set to `true` to stop Firefox reading policies from local policy sources.
- Set to `false` to read local policy sources. This is the same as not setting the policy.
