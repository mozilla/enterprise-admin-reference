Configure proxy settings.
These settings correspond to the connection settings in Firefox preferences.

Unless you lock this policy, changes the user already has in place will take effect.

> [!NOTE]
> In the [Windows ADMX templates](https://github.com/mozilla/policy-templates/tree/master/windows), these settings were moved to their own category to make them easier to configure via Intune.

## Values

- `Mode`: the proxy method being used.
- `Locked`: whether or not proxy settings can be changed by users.
- `HTTPProxy`: the proxy server used for HTTP requests.
- `UseHTTPProxyForAllProtocols`: define whether or not `HTTPProxy` is also used for HTTPS traffic, overriding `SSLProxy`.
  It doesn't affect `SOCKSProxy`.
- `SSLProxy`: the proxy server used for HTTPS requests.
- `FTPProxy`: _Deprecated_, has no effect since Firefox 90.
- `SOCKSProxy`: the SOCKS proxy server.
- `SOCKSVersion`: the SOCKS version (4 or 5).
- `Passthrough`: list of hostnames or IP addresses that will not be proxied.
  Use `<local>` to bypass proxying for all hostnames which do not contain periods.
- `AutoConfigURL`: a URL for proxy configuration (only used when `Mode` is `autoConfig`).
- `AutoLogin`: don't prompt for authentication if a password is saved.
- `UseProxyForDNS`: whether or not to look up host names through the SOCKS proxy, for both SOCKS v4 and v5.
  Firefox already does this for SOCKS v5 by default, so setting this to `false` makes SOCKS v5 DNS lookups bypass the proxy.

> [!NOTE]
> You must specify `HTTPProxy`, `SSLProxy` and `SOCKSProxy` as a host name and port without a [scheme](https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Schemes), for example `proxy.example.com:8080`.
>
> Always include the proxy's port.
> Port `443` isn't valid this policy: if your proxy listens on port `443`, use a PAC file instead.

## Examples

<PolicyExample policy="Proxy" />

### Using a proxy auto-configuration (PAC) file

A PAC file decides which proxy each site uses, so you can change your proxy rules on the server without deploying a new policy.
`Locked` stops users from changing the connection settings, and makes Firefox ignore any proxy settings they had already changed:

```json
{
  "policies": {
    "Proxy": {
      "Mode": "autoConfig",
      "AutoConfigURL": "https://proxy.example.com/proxy.pac",
      "Locked": true
    }
  }
}
```

### Using a proxy server for HTTP and HTTPS

Set `HTTPProxy` to the proxy's host name and port, without `http://`.
The `UseHTTPProxyForAllProtocols` value also sends HTTPS sites through the proxy.
In this example, omitting `UseHTTPProxyForAllProtocols` would make HTTPS requests bypass the proxy.

`Passthrough` specifies a comma-separated list of sites that won't use the proxy.
In this example:

- `<local>` matches host names without a dot, like `intranet`.
- `example.com` matches `example.com` and all of its subdomains.
- `10.0.0.0/8` only matches sites visited by IP address, not host names that resolve to an address in that range.

By default, Firefox bypasses the proxy for `localhost`, `127.0.0.1`, and `::1`, so you don't need to list them explicitly:

```json
{
  "policies": {
    "Proxy": {
      "Mode": "manual",
      "HTTPProxy": "proxy.example.com:8080",
      "UseHTTPProxyForAllProtocols": true,
      "Passthrough": "<local>, example.com, 10.0.0.0/8",
      "Locked": true
    }
  }
}
```

### Using the operating system's proxy settings

Firefox uses the system proxy settings by default.
If you already manage the proxy in the operating system via Group Policy or a configuration profile, lock this `Mode` so users can't set a different proxy in Firefox:

```json
{
  "policies": {
    "Proxy": {
      "Mode": "system",
      "Locked": true
    }
  }
}
```

## Windows (GPO)

```
Software\Policies\Mozilla\Firefox\Proxy\Mode = "none" | "system" | "manual" | "autoDetect" | "autoConfig"
Software\Policies\Mozilla\Firefox\Proxy\Locked = 0x1 | 0x0
Software\Policies\Mozilla\Firefox\Proxy\HTTPProxy = httpproxy.example.com:8080
Software\Policies\Mozilla\Firefox\Proxy\UseHTTPProxyForAllProtocols = 0x1 | 0x0
Software\Policies\Mozilla\Firefox\Proxy\SSLProxy = sslproxy.example.com:8080
Software\Policies\Mozilla\Firefox\Proxy\SOCKSProxy = socksproxy.example.com:1080
Software\Policies\Mozilla\Firefox\Proxy\SOCKSVersion = 0x4 | 0x5
Software\Policies\Mozilla\Firefox\Proxy\Passthrough = <local>
Software\Policies\Mozilla\Firefox\Proxy\AutoConfigURL = URL_TO_AUTOCONFIG
Software\Policies\Mozilla\Firefox\Proxy\AutoLogin = 0x1 | 0x0
Software\Policies\Mozilla\Firefox\Proxy\UseProxyForDNS = 0x1 | 0x0
```

```xml
  </dict>

```
